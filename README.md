# Butter 'n' Toast — website

One page. `index.html` is the whole site.

## Files
- `index.html` — the page
- `CNAME` — tells GitHub Pages the custom domain is butterntoast.com. Don't delete it.

## To preview
Double-click `index.html`. It opens in your browser.

## To edit text
Open `index.html` in Notepad (or any text editor), change the words between
the tags, save, and re-upload to GitHub.

## Images
Images currently load from ActiveCampaign's public image server.
If you want them stored with the site instead, save each one and put it
in an `images/` folder, then swap the long https:// addresses in
index.html for `images/<filename>`.
